# Programming in Linux

Материалы курса «Программирование в Linux» (СПбГУ, кафедра технологии программирования).

Сайт: https://efreit0r.github.io/Programming-in-Linux/

## Что здесь лежит

- `index.html` — главная страница курса и карта устройства ядра Linux.
- `01/`, `02/`, `03/`, `04/`, `4.5/` — собранные презентации открытых лекций (Slidev).
- `04/examples.tar.gz` — примеры к лекции 04 (после распаковки — `Chapter 04/`).

Файл собран из исходников курса: `scripts/build-site.mjs` и `decks.json`.
Править `index.html` руками бессмысленно — при следующей публикации он
перезапишется. Добавить или открыть лекцию — это `decks.json` в репозитории курса.

## Примеры к практикумам

Перед занятием скачайте архив и распакуйте его в рабочую папку:

```bash
# лекция 04
mkdir -p ~/build-lab && cd ~/build-lab
curl -LO https://efreit0r.github.io/Programming-in-Linux/04/examples.tar.gz
tar xzf examples.tar.gz    # появится каталог «Chapter 04»
```

Внутри архива нет результатов сборки: `make clean` перед упаковкой уже сделан.

Здесь только собранные материалы для студентов: исходники лекций
и ещё не пройденные колоды в этот репозиторий не публикуются.
