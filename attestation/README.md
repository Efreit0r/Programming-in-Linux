# Промежуточная аттестация по лекциям 1–4

Один файл, ничего устанавливать не нужно. Нужен только `python3`
(он есть в любой учебной системе Linux).

## Как запустить

```bash
python3 attestation.py
```

Или, если файл сделан исполняемым:

```bash
chmod +x attestation.py
./attestation.py
```

## Что происходит

1. Спросит фамилию, имя и группу — они попадут в ведомость.
2. Задаст 16 вопросов по лекциям 1–4: история Linux, командная строка,
   Bash, сборка программ.
3. На всё — **30 минут**. Таймер виден в строке ответа: `[27:41]`.
4. Ответ принимается **один раз**. Вернуться к вопросу и исправить нельзя.
5. После последнего вопроса тест закроется сам и покажет результат.

## Результат

Файл сохраняется в папку `vk workspace` рядом с тем местом, откуда
запускали тест:

```
vk workspace/Иванов_Иван_21-А_2026-11-01_23-06.txt
```

Внутри: ФИО, группа, время начала и конца, сколько правильных ответов,
оценка «зачтено / не зачтено» и разбор каждого ответа.

Этот файл и нужно сдать преподавателю.

## Правила

- **Выйти из теста нельзя.** `Ctrl+C`, `Ctrl+D` и закрытие окна терминала
  означают, что попытка прервана: ответы фиксируются как есть.
- `Ctrl+Z` не останавливает тест.
- Если время вышло во время вопроса, тест закрывается сам, а неотвеченные
  вопросы считаются неверными.
- Порог: **60%** правильных ответов.

## Для преподавателя

Время можно изменить, не трогая код:

```bash
ATTESTATION_MINUTES=45 python3 attestation.py
```

Папку для результатов тоже:

```bash
ATTESTATION_OUT="$HOME/результаты" python3 attestation.py
```

Вопросы лежат в списке `QUESTIONS` в начале файла: текст, варианты,
номер правильного (с нуля → но в поле `correct` считается с 1).
Добавить вопрос — дописать словарь в список, больше ничего менять не нужно.

Ответы проверяются в конце, поэтому в самом тесте правильный ответ
никуда не выводится — списать из вывода нельзя.
